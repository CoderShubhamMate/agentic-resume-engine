# Stripe - Backend Software Engineer

## Application Context

Company: Stripe
Role: Backend Software Engineer
Job ID: JR-48291
Location: Austin, TX (Hybrid)
Employment: Full-time
Source: LinkedIn

## Customization Focus

Focus on backend API development, Java/Python microservices, database design, fintech domain experience, REST APIs, and testing practices.

## Job Description

Stripe is looking for a Backend Software Engineer to join our Payments Infrastructure team.
You will design, build, and maintain high-availability APIs that process millions of transactions per day.

**Responsibilities:**
- Design and implement RESTful APIs and microservices for payment processing flows.
- Collaborate with product and frontend teams to deliver reliable, low-latency backend services.
- Write clean, well-tested code and participate in code reviews.
- Diagnose and resolve production issues across distributed systems.
- Document architecture decisions and contribute to internal engineering standards.

**Minimum Qualifications:**
- Bachelor's degree in Computer Science or equivalent experience.
- 1+ years of experience in backend software development.
- Proficiency in Java or Python.
- Experience with REST API design and SQL databases.
- Familiarity with Git and collaborative development workflows.

**Preferred Qualifications:**
- Experience with Spring Boot or FastAPI.
- Exposure to Docker or containerization.
- Knowledge of CI/CD pipelines.
- Experience in fintech or high-throughput transaction systems.
